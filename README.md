# 算法手撕高频题库

> 1. 目标是成为目前最全、最优质的算法手撕高频题库。
> 2. 该题库适用岗位：前端开发（AI 全栈）、大模型应用开发、后端开发（AI 全栈）、测试开发、算法开发、AI Infra、FDE 等。
> 3. 所有题均来自真实面经，由本人从近期 1000+ 份面经提取总结。

## 仓库结构

```
leet-code/
├── js-ts-question-bank/       # js、ts 手写题、力扣、校招笔试
├── java-question-bank/
│   └── leet-code/                # java 手撕、力扣、校招笔试
└── ...
```

## 约定

- **力扣题**：文件名直接用题号，如 `104.ts`、`1143.java`，方便和题解对照；同一题同时保留多语言版本。
- **手写题**：文件名即题目，如 `数组去重.js`、`封装延迟Promise.js`。
